Medicine price API for Pakistan

Search DRAP-registered medicines, get the official maximum retail price, find brands with the same formula, strength and form, and work out the cheapest way to buy a list of medicines.

Authentication

Base URL: https://sasta-dawa-finder.vercel.app/api/v1

Create a key in your account (API keys tab). Send it in the X-API-Key header with every request. Keys look like sdk_ followed by 40 hex characters. The full key is shown only once; we store only a hash of it.

Keep keys on your server. Do not put them in web pages or mobile apps where anyone can read them.

Search medicines

GET /api/v1?a=search&q=<text>&limit=<1-50>: brand or formula name, typo tolerant. limit defaults to 10.

curl -H "X-API-Key: $SD_KEY" \
  "https://sasta-dawa-finder.vercel.app/api/v1?a=search&q=panadol&limit=5"
{
  "query": "panadol",
  "results": [ { "id": "...", "brand": "Panadol", "formula": "Paracetamol", ... } ]
}

One medicine

GET /api/v1?a=medicine&id=<id>: use an id from search results.

curl -H "X-API-Key: $SD_KEY" \
  "https://sasta-dawa-finder.vercel.app/api/v1?a=medicine&id=MEDICINE_ID"

Returns { "medicine": { ...fields } }, or 404 for an unknown id.

Same-formula alternatives

GET /api/v1?a=alternatives&id=<id>: brands with the same ingredients, strength and form and a comparable pack, cheapest per unit first (up to 30, including the medicine itself).

{
  "medicine": { ...fields },
  "alternatives": [ { ...fields, "percent_vs_selected": -42 } ]
}

percent_vs_selected compares the unit price with the selected medicine: negative means cheaper.

Optimise a medicine list

POST /api/v1?a=optimise with a JSON body {"items":[{"id":"...","qty":60}]}. qty is in units (tablets, capsules, ml). Up to 300 items; unknown ids are skipped.

curl -X POST -H "X-API-Key: $SD_KEY" -H "Content-Type: application/json" \
  -d '{"items":[{"id":"MEDICINE_ID","qty":60}]}' \
  "https://sasta-dawa-finder.vercel.app/api/v1?a=optimise"
{
  "rows": [ { "medicine": {...}, "qty": 60, "cheapest": {...},
              "cost_now": 900, "cost_best": 420, "saving": 480 } ],
  "total_now": 900, "total_best": 420, "saving": 480, "percent": 53
}

JavaScript (Node 18+)

const API = 'https://sasta-dawa-finder.vercel.app/api/v1';
const headers = { 'X-API-Key': process.env.SD_KEY };

const { results } = await fetch(`${API}?a=search&q=${encodeURIComponent('augmentin 625')}`, { headers })
  .then((r) => r.json());

const { alternatives } = await fetch(`${API}?a=alternatives&id=${results[0].id}`, { headers })
  .then((r) => r.json());
console.log(alternatives[0].brand, alternatives[0].unit_price_rs);

const plan = await fetch(`${API}?a=optimise`, {
  method: 'POST',
  headers: { ...headers, 'Content-Type': 'application/json' },
  body: JSON.stringify({ items: [{ id: results[0].id, qty: 30 }] }),
}).then((r) => r.json());
console.log('Saving: Rs', plan.saving);

Medicine fields

FieldMeaning
idStable medicine id (use it with medicine, alternatives, optimise)
brandBrand name, e.g. Panadol
productFull product name as listed by DRAP
formulaActive ingredient(s)
strengthStrength, e.g. 500mg
formDosage form, e.g. Tablet, Syrup
packPack size as listed
pack_price_rsMaximum retail price of the pack, in rupees
unit_price_rsPrice per tablet / ml / unit (pack price ÷ units), 2 decimals
manufacturerManufacturer or importer
drap_reg_noDRAP registration number, or null
price_effective_fromDate the price became effective

Prices come from DRAP's public price index and may change. This data is not medical advice: brand switches should be confirmed by a doctor or pharmacist.

Errors

Errors return JSON {"error":"message"} with an HTTP status:

400Missing parameter, e.g. no q
401Missing, invalid or revoked API key
404Unknown medicine id or action
429Daily limit reached
