    Updating medicine prices from DRAP

    1. On your PC, in the project folder, run npm run sync-data (takes about an hour, it downloads DRAP's price list slowly).
    2. Run npm test, then git add -A, git commit -m "Update prices" and git push.
    3. Vercel deploys the new prices automatically. Your price fixes here stay applied.
