    Quick actions

    Updating medicine prices from DRAP

    1. On your PC, in the project folder, run npm run sync-data (takes about an hour, it downloads DRAP's price list slowly).
    2. Run npm test, then git add -A, git commit -m "Update prices" and git push.
    3. Vercel deploys the new prices automatically. Your price fixes here stay applied.

    How to turn on daily backups

    1. Open your project on vercel.com → Settings → Environment Variables.
    2. Add CRON_SECRET with a long random value (for example 40 random letters and numbers). Nobody needs to type it; Vercel sends it by itself.
    3. Press Redeploy. A backup is then saved every night at 2:00 am Pakistan time, and the last 14 are kept.

    Restore from a backup file

    Puts the saved records from a backup file back. Merge mode: records in the file replace the same records on the site; records that are not in the file are left alone. Needs 2-step login (Security tab).

    Security

    2-step login: after the password, the admin panel also asks for a 6-digit code from the Google Authenticator app on your phone. Someone who learns the password still cannot get in.

    Locked out? (emergency)

    If you lost your phone and your recovery codes:

    1. On vercel.com → your project → Settings → Environment Variables, add ADMIN_2FA_RESET with the value 1, then Redeploy.
    2. Sign in with just the admin password. The server deletes the old 2-step login setup.
    3. Remove ADMIN_2FA_RESET again and redeploy (while it is set, 2-step login is switched off for everyone).
    4. Come back here and turn 2-step login on again with your new phone.

    Only someone with access to your Vercel account can do this, so keep that account safe too (use 2-step login on Vercel and on your email).

    Changing ADMIN_PASSWORD signs everyone out but does not turn 2-step login off.
